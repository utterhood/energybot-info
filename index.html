EnergyBot NOVEC

Electricity, solar and electric-vehicle energy monitoring for personal use.

EnergyBot brings together local energy records, charging information and utility billing evidence in a dashboard on its operator’s Windows computer. It is privately operated by Jeffrey Crook and is not offered for public signup.

Why EnergyBot uses Gmail

The optional NOVEC integration identifies genuine bill-ready notifications and records their arrival for billing review. The supervised notification check has been validated; unattended monitoring and automatic statement retrieval have not been activated.

EnergyBot requests only read-only Gmail access. Google’s permission technically allows mailbox-wide reading. EnergyBot restricts message-content processing to candidate NOVEC notices and checks their sender, authentication and expected account details.

It does not send, change or delete email. Relevant notification metadata is stored locally; operator-configured backups or file synchronization may copy those records. OAuth tokens are encrypted for the current Windows user and stored outside Dropbox.

Read the EnergyBot privacy policy for data use, retention, sharing and revocation details.

Terms of use

This page describes a private application. It provides no public account, subscription or hosted energy-monitoring service.
